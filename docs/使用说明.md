# 澄流 TV 使用说明

## 给第一次使用的人

这个应用像一个电视上的播放器和网址收藏夹。它不自带节目，先由家人添加频道或网站，之后用遥控器选择即可。

遥控器的基本用法：方向键移动蓝色焦点，确定键打开选中的按钮，返回键退回上一级，菜单键打开当前播放或网页工具。直播播放时，上下键换台，确定键打开频道选择；网页播放按当前界面提示操作。

## 添加直播频道

首页点「看电视」。没有频道时会打开「一键导入频道」：

- 有文件：选「选择源文件」，找到自己准备的 M3U 或 TXT 文件。
- 有网址：选「使用订阅链接」，输入完整地址，点「识别频道」。可以填写订阅文件、包含直播清单的 TVBox JSON，或挂载这些文件的网页。

看到预览后，确认频道再导入。订阅有多个候选文件时，先选你需要的那一个。播放地址失效、文件只有网站插件而没有直播清单、网页要求登录，都可能导致不能导入或播放。

导入后在频道列表按确定播放。同一频道只显示一个卡片，来自不同地址的线路仍保留；播放中从菜单进入更多播放设置，可选择备用线路。

后续更新：回首页点「家人设置 → 更新已保存的频道订阅」。源管理在「家人设置 → 管理直播源」，可以检测、分类、清理和清空。删除前请看清确认框；本地移除不等于删除远端文件。

## 保存影视网站、导航或源集合

进入「看影视 → 添加网站」，填完整网址并保存。

- 普通影视站：点击入口进入，支持时可显示分类、封面、简介和站内搜索。
- 影视导航站：能识别时会进入「发现影视网站」，显示原站网站清单和分类。选中网站右侧的「添加」，之后在自己的「影视网站」中打开。
- 挂载直播源集合的网页：在该网站入口旁选「更多 → 读取/更新源」，选择识别到的文件，预览并导入。保存订阅后可以再次更新。

识别不了的页面仍可打开原网页，用遥控适配操作。不同网站结构不同，应用无法保证所有导航和播放器都兼容。

播放页画面还在小窗口时，按遥控器菜单键，选「全屏」。标准版支持补充嵌套播放器的放大，进入后可用确定键播放 / 暂停；按返回退出全屏并恢复原网页。没有识别到播放器时，请先在网站里选择剧集或进入播放页。原视频比例与屏幕不同时保留黑边，避免人物被拉宽或裁切。

放大后模糊时，按菜单选择「画质」查看真实视频分辨率，点「原站选择画质」回网站播放器选择它提供的高清选项。低分辨率原视频铺满大电视会更明显；应用不会重新压缩，也不会凭空增加细节。

## 点选网页广告并自动隐藏

1. 打开网页，按菜单键，进入「广告防护」。
2. 选「点选网页广告并隐藏」，用方向键把光标移到广告区域。蓝框表示选中的元素。
3. 按确定，检查提示，选「保存并屏蔽」。默认焦点在取消，避免误操作。
4. 下次从应用打开这个网站，会自动隐藏匹配区域。网页结构改变时可能需要重选。

不想保存时按返回取消。误选后在「广告防护 → 清除本站点选规则」恢复，或在「选择防护开关」关闭「我的点选屏蔽规则」。不允许直接选择整个网页和视频画面。

「基础广告请求拦截」使用小范围规则；「隐藏常见网页广告位」处理可识别网页元素；「开发者站点增强插件」控制随代码打包的站点增强。播放器不正常时，可先试「本站全部关闭」。这些开关按网站保存；不保证处理视频贴片、跨域播放器内部或特殊绘制的广告，也没有下载或导入外部插件的入口。

## 一键搜索多个影视网站

1. 从首页或「影视网站」进入「一键搜片」。
2. 先点「搜索范围」，勾选已经保存的具体影视网站，也可在这里「添加网站」。
3. 输入片名，点「一键搜索」，结果按网站分别显示。
4. 方向键选影片，按确定进入预览，再选播放或收藏。

首次默认选择已保存的前 3 个可搜索影视网站；可以自己改，最多同时选 6 个。没有添加网站时，范围为空。网站导航页和直播入口不是影视片库，不能作为跨站片名搜索目标。个别网站失败时，其他网站的结果仍能显示。

不能自动找到搜索入口时，可以在该网站的「更多 → 搜索设置（家人）」中设置自定义搜索地址，把片名位置改成 `{query}`。这项由熟悉网站的家人处理即可。

## 收藏后下次直接看

影片预览中选「收藏影片」；网站入口旁选「收藏」；直播频道可从播放菜单中收藏。首页底部「收藏」可分别查看影片、网站和频道。

收藏保存的是你选中的原网站入口、影片页和频道信息。网站下架影片或地址变化后，原收藏也可能失效。

## 兼容版网页打不开

兼容版使用盒子自带的 Android System WebView。缺少或版本过旧时，需要更新系统网页组件；Android 9 及以上 ARM 设备可优先使用标准版。是否支持特定盒子，还受系统、安装限制和硬件解码能力影响。
