# 基础广告防护的范围

本版使用项目自写的保守匹配逻辑，只识别两个基础广告服务域名及其子域名：`doubleclick.net`、`googlesyndication.com`。不下载或附带 EasyList 全表，不宣称达到成熟广告拦截器的覆盖率。

域名分类参考 [EasyList 官方列表](https://easylist.to/easylist/easylist.txt)。该列表也包含大量站点例外；本项目为减少误伤，默认保留主文档、媒体扩展名、`/ssai/` 和 `/ondemand/hls/` 等可能承载节目的视频路径。实际规则见 `adblock-rules.json` 和 `AdRequestPolicy.java`；标准版使用相同边界的 WebExtension 回调。

网页隐藏只匹配少量明确广告标记。手动点选则保存用户确认过的 CSS 选择器，每站最多 100 条，用户可以关闭或清除。规则不读取或更换视频流、不关闭登录和鉴权，也不承诺跳过服务器混入节目的视频广告。

网站结构、域名、播放器和反广告机制会变化。页面损坏或视频不播时，应先尝试关闭本站防护。开发者新增规则时，请附带正常内容未被误隐藏的回归测试。
