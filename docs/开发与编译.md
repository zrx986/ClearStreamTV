# 开发与编译

项目使用 Java 17、Gradle 8.11.1、Android Gradle Plugin 8.10.1；安装 Android SDK 36 与所需构建工具。标准版最低 API 28，兼容版最低 API 23，target API 35。

1. 克隆仓库到英文路径，例如 `D:/projects/ClearStreamTV`。较旧测试运行器在中文路径下可能无法加载 JUnit 测试类。
2. 用 Android Studio 打开并设置 SDK，或设置 `ANDROID_HOME` / `local.properties`。本机路径不提交到仓库。
3. Windows 使用 `gradlew.bat`，macOS / Linux 使用 `./gradlew`。

```sh
./gradlew :core:test
./gradlew :app:assembleStandardDebug :app:assembleCompatibleDebug
```

安装包位于 `app/build/outputs/apk/`。标准版默认包含 ARM32 和 ARM64；x86_64 模拟器可用 `-PengineAbi=x86_64` 构建。测试 APK 只用于测试，不作为日常安装包。

```sh
./gradlew :app:connectedStandardDebugAndroidTest -PengineAbi=x86_64 \
  -Pandroid.testInstrumentationRunnerArguments.class=tv.clearstream.SourceFreeUiTest
```

界面测试会清理测试应用数据，只能在专用模拟器中运行。测试使用回环服务器、保留示例域名和自行生成的测试画面，均不会导入到生产 APK。

模块：`core` 负责 URL / 清单解析、同台识别、搜索规则及状态判断；`app` 负责电视界面、存储、网络和播放。`standard` 增加 GeckoView 网页内核，`compatible` 使用系统 WebView。`tools/check_source_free.py` 检查发布文件中是否意外包含预置清单、本机配置或个人数据。

本版本使用开发签名，适合试用与复核。正式发行需自行配置发布签名，更新网页内核，并按所使用依赖的许可证处理分发。不要把签名文件、密码、用户导出的数据库和订阅放进仓库。
