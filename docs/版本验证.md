# 0.1.13 无源版验证

本次验证日期：2026-10-27。版本号 `0.1.13`，versionCode `14`，独立安装标识 `tv.clearstream.nosource`。不会继承个人版 `tv.clearstream` 的频道、网站或收藏。

| 范围 | 结果 |
| --- | --- |
| 核心逻辑 | 67 项通过，0 失败 / 错误，包括双栈策略、清单解析、同台归并和广告过滤边界。 |
| 标准版电视流程 | Android 9 / API 28 模拟器，最终选定的 26 项通过，0 失败。 |
| 1080p 补充检查 | 同一生产代码，新增的本地 1920×1080 样本在跨域 iframe 中全屏，播放推进与返回恢复通过。 |
| 兼容版电视流程 | 同一 Android 9 模拟器、系统 WebView 66，10 项通过，0 失败。 |
| 网页 DOM 回归 | 播放器放大 / 还原、跨域协调、插件生命周期、广告点选 / 恢复、请求拦截及遥控焦点通过。 |
| 编译 / 静态检查 | 两版编译通过，Lint 0 错误；标准版 15 条、兼容版 14 条警告。 |

标准版流程涵盖：首次没有任何频道和网站；遥控进入导入和添加网站；只搜索自己添加的网站；多站结果及失败隔离；影片预览 / 收藏；导航网站读取和添加；同名不同地址保存；全屏进入和退出；实际画质显示；点选广告、确认、重开后自动隐藏及清除恢复；基本广告请求拦截和常见广告位隐藏。

兼容版复核涵盖：广告请求拦截、点选屏蔽保存与清除、实际播放器放大及返回还原、空状态与导入引导、添加搜索网站、多站搜索预览 / 收藏、同台多线路持久保存。不是全部 Android 6 盒子的验收。

网页测试使用自建回环服务器，海报为测试代码绘制；320×180 与 1920×1080 视频使用合成测试图生成。示例不属于可用影视源，不放入生产 APK。1080p 是解码的视频尺寸，截图与测试屏幕为 1280×720；不能据此声称实体电视 4K 输出或所有网站都可高清播放。

发现并修复的问题包括：兼容版全屏按钮以前仅隐藏工具栏；标准版不能放大跨域 iframe 的内部播放器；嵌套画面遥控播放操作不足；广告开关在异步载入旧配置时可能被覆盖。测试过程中还修正了旧 WebView 不支持新语法的测试页面、CSS 像素与物理像素混淆的断言，以及确认框方向的测试预期。

保留的限制：没有覆盖所有网站，没有测试朋友的中兴 / 华为实体盒子、长时间播放、4K HDMI 输出或所有地域网络；复杂嵌套 / 封闭播放器仍可能不兼容。视频贴片、服务端混入广告及跨域页面内部的点选屏蔽不保证支持。画质只由源与网站实际提供，应用不会把低清视频增强成真正 4K。
