# 站点适配与插件开发

本版提供开发者接口和一个保留域名示例。开发者修改规则后重新编译，可给某个网站补布局、遥控焦点或网页广告处理。普通用户可以使用「广告防护」里的基础规则和手动点选屏蔽；当前没有导入任意第三方插件的界面，也不附带现成影视站贴片跳过规则。

## 现有模块

| 文件 / 模块 | 负责什么 |
| --- | --- |
| `app/src/main/assets/site-reader.js` | 识别影片卡片、封面、简介与搜索表单。 |
| `app/src/main/assets/directory-reader.js` | 读取导航网站列表；不是把装饰图片当影片。 |
| `core/.../HtmlSourceLinks.java`、订阅导入模块 | 识别清单文件、网页挂载的候选订阅和直播清单。 |
| `app/src/main/assets/tv-adapter.js` | 通用遥控焦点、布局和按键导航。 |
| `app/src/main/assets/player-layout.js` | 保留原播放器节点并放大；标准版额外协调跨站 iframe 内部布局。 |
| `app/src/main/assets/site-plugins.js` | 插件注册、域名匹配、启停、后台清理与异常隔离。 |
| `app/src/main/assets/site-plugins-custom.js` | 开发者扩展入口；当前只有 `demo.example` 的演示规则。 |
| `app/src/main/assets/adblock-rules.json`、`adblock-dom.js` | 小范围广告请求 / 元素规则、手动点选和可恢复的元素隐藏。 |
| `app/src/standard/assets/tv-engine/adblock-background.js` | 标准版网络请求拦截与按站点关闭；兼容版由 WebView 资源回调处理。 |

## 一个插件示例

编辑 `site-plugins-custom.js`，注册规则：

```js
ClearStreamTVPlugins.register({
  id: 'example.tv-layout',
  hosts: ['your-site.example'],
  mount: function (ctx) {
    ctx.addStyle('.film-card { min-height: 64px; font-size: 22px; }');
    ctx.observe(function () {
      ctx.focusable('.episode-item');
      ctx.hide('.site-ad-banner');
      ctx.clickOnce('button[data-site-skip-ad]');
    });
  }
});
```

这里的域名和选择器都是示例，必须针对目标网站的真实结构修改，不能直接当成通用规则。

## 接口说明

- `register({id, hosts, mount})`：注册唯一插件；`hosts` 精确匹配域名，不自动包含子域名。
- `ctx.addStyle(css)`：加入样式；停用插件时移除。
- `ctx.hide(selector)`：隐藏匹配区域；停用时恢复原来的 `display`。
- `ctx.focusable(selector)`：为原本没有 `tabindex` 的元素增加焦点，并刷新遥控目标。
- `ctx.clickOnce(selector)`：对可见、未禁用的元素尝试一次普通网页点击；同一节点不会反复点击。可以用在原网页已经提供的跳过广告按钮，不能保证所有播放器会接受这种点击。
- `ctx.observe(fn)`：首次执行一次，之后在 DOM 子节点变化时合并触发。停用时取消观察和待执行任务。
- `ctx.onCleanup(fn)`：登记自定义清理，例如移除事件监听。
- `mount` 也可以返回一个清理函数。
- `ClearStreamTVPlugins.status()`：查看已注册、运行中和发生错误的插件 ID。

电视适配模式开启时才运行匹配插件；切换原始网页、应用退到后台或页面不可见时停止并清理。一个插件出错，不会阻止其他插件运行。只在顶层站点注入插件接口；嵌套播放器全屏协调是独立的布局组件。

这是应用内随源码打包的扩展代码，不是权限隔离的第三方插件容器。不要在规则中加入凭据、采集数据或自动添加源，也不要把清理 UI 的规则写成修改登录、支付或播放器鉴权的逻辑。

## 全屏与兼容性范围

普通网页视频优先沿用浏览器全屏。标准版对找不到顶层视频的嵌套播放器补充布局全屏，并在子页面中放大原播放器；兼容版不再只隐藏工具栏，而是放大识别到的视频或 iframe。退出后恢复原布局，不重新创建播放器、不替换视频地址，视频按原比例显示。

兼容版对不同域名 iframe 内部的进一步适配仍受系统 WebView 能力影响。Canvas / 特殊封闭播放器、网站中途替换整个容器、复杂多重嵌套、特定站点登录或播放限制，仍可能需要单独适配；不要以“网页打开了”代替实播验证。

本地 DOM 回归：安装 Node.js 与 Playwright，设置 `CHROME_PATH` 指向现有 Chromium / Edge 后运行：

```sh
node tools/player-layout-test.js
node tools/site-plugins-test.js
node tools/tv-adapter-test.js
node tools/adblock-test.js
```

这些 DOM 测试只使用本地生成的页面，不访问真实影视平台。安卓侧的 `ModernBrowserTest`、`WebFullscreenTest` 和 `AdProtectionUiTest` 另行检查遥控全屏、播放推进、点选保存恢复以及请求拦截。广告请求测试使用一个已知广告域名的测试资源请求，应被本地拦截，并不以该服务响应为成功条件。
