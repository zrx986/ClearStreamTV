# 隐私说明

应用没有账号注册，也没有项目自建的用户数据服务器。频道、订阅地址、网站、收藏和设置保存在本机；应用不会将这些清单上传给项目作者。卸载本版会删除本版的本地数据，除非用户自行另外导出保存。

添加订阅、打开网站、加载封面、搜索和播放时，设备会访问用户选择的网站及其媒体服务。这些服务可能获得 IP 地址、请求内容和正常网页产生的 Cookie。网页内的广告、登录和隐私规则由对应网站提供。

用户主动进行外网网络检测时，会访问 Cloudflare 的公开诊断服务，以辅助检查当前连接。它不是直播源，也不用于添加节目。

广告防护开关和点选屏蔽规则也只保存在本机。基础拦截在设备上处理请求；不会把浏览记录发送给广告规则提供方。用户清除本站规则或关闭防护后，隐藏的区域可恢复。开发者自行加入的第三方代码应另外审查。

源码仓库与发布包不附带作者的频道、网站集合、真实订阅、账户、签名密钥或使用历史。示例截图使用本地生成的测试页面；示例内容不随应用预置。
